# 問い合わせナレッジ検索

Docker Composeで動作する、Excel問い合わせ履歴の類似検索試作です。架空の履歴6件を初期登録しています。

## 起動

WSLターミナルでこのフォルダに移動して実行します。

    docker compose up --build

ブラウザで `http://localhost:8000` を開きます。停止は `docker compose down` です。

画面右上からCSVまたはXLSXを選択します。先頭シートの1行目に、次の列がすべて必要です。

- 受付日、問い合わせ内容、問い合わせ種類、回答内容
- 対象カテゴリ、他部署へのエスカレーション有無、問い合わせ言語、該当データを回答できたか

取込データは `data/inquiries.json` に保存されます。実データを投入する前に、氏名・メールアドレス・電話番号などの個人情報をマスキングしてください。
